Fill mode: a page built around one long table can stay as tall as the window, so the table scrolls under the controls above it and the controls below it stay in view. The page sets `{% set fill_viewport = true %}` before its blocks, gives each element between its `page` block and the table the `fill-chain` class, and gives the scrolling element, usually a `.table-scroll`, the `fill-region` class. Its sticky header row stays in view while the rows scroll. From lg up the page wrapper then fills the window; below lg the page scrolls as a whole, because a table scrolling inside a phone-sized window leaves little room to read it. A page whose columns stack below xl sets `fill_viewport` to "xl" instead, and the page scrolls as a whole until then.
