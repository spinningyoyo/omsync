{% extends "layouts/guide.html" %} {% from "guides/parts.html" import section, figure, try_it with context %} {% set sections = [ ("sync", "Bank sync"), ("files", "Statement files"), ("review", "Needs review"), ] %} {% block guide_body %} {% call section("sync", "Bank sync") %}
  • Banks: Bank of America, Chase, Citi, and Fidelity Rewards.
  • Open Settings → Bank sync → Add provider. Choose the bank, its Bitwarden login, and the accounts.
  • omsync keeps only the name of the Bitwarden login, never the password.
  • A sync opens Chrome. Keep the window open until the sync ends.
  • When the bank asks for a code or an approval in its app, omsync asks you on the page.
  • The demo cannot sync.
{{ figure("statements-bank-sync", "The Bank sync page in the demo: a notice that bank sync is off, then 'No providers yet' and each bank's accounts marked Not synced.", "In the demo, no bank is set up yet.") }} {{ try_it("/settings/providers", "Open Bank sync") }} {% endcall %} {% call section("files", "Statement files") %}
  • omsync reads OFX and QFX files, and Bank of America CSV files.
  • Put each file in the bank's folder in your data folder, such as statements/CHASE. Add provider imports the files that are already there.
  • A Bank of America CSV goes in a folder named for the account's last four digits, such as statements/BOA/4821.
  • Files that overlap are fine. omsync never counts a transaction twice.
  • You can undo each file's import on its own.

  • Same as: it is that transaction.
  • Add as new transaction: it is a different one.
