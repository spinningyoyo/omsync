Plan shows this month's budget and your goals. Open Budget to plan a month. The arrows move between months, and This month comes back to the current one. A budget line is a planned amount for one category in one month.

Spending in a category with no budget line is shown as unbudgeted. It is not added to the budgeted totals, so the totals stay honest.

The budget has two modes, chosen with the Flex and Category buttons. Both show what is still available as Left.

Switching modes keeps every line and setting you have made. Only the way the page presents them changes.

{% endcall %} {% call section("flex", "How the flex number is worked out") %}

In flex mode, the flex number is the money left for flexible spending:

Flex number = expected income − fixed budgets − non-monthly budgets − active goal contributions

Expected income is the average of the three complete months before the month you are planning, including months with no income. You can set an income figure yourself, and the figure you set replaces the average. You can also set the flex number for one month, which replaces the calculated one for that month only.

Progress bars show actual spending against what is available. Under half is good, from half to just under the whole is a warning, and the whole or more is over.

{% endcall %} {% call section("rollover", "Rollover and copying") %}

Roll over is a switch on a line. For a non-monthly category, it carries what you did not spend into the next months, so a yearly cost is saved for rather than surprising you. Overspending carries as a negative amount. New non-monthly lines in flex mode start with rollover on, because irregular costs are funded across months.

Two buttons save typing. Copy last month copies the previous month's lines, but only into a month with no lines yet, so it never overwrites work you have done. Quick fill with last budget adds last month's line to each fixed category that has none this month. It never changes a line that exists.

{% endcall %} {% call section("goals", "Goals") %}

A goal is a target, such as an emergency fund or a trip. It has a name, a target amount, an optional target date, a linked account, and a monthly contribution. Its saved amount is the linked account's latest reported balance, so its progress is only as current as the last statement you imported.

A goal's monthly contribution is a plan, not a transfer. It reduces the flex number, but it moves no money and creates no transaction. Several goals can point at the same account, and they do not each reserve part of it.

The Recurring page lists the things that repeat: bills, subscriptions, and paychecks. omsync finds likely ones by looking for a payee that charges on a steady schedule. It only suggests them. Nothing counts toward a total until you confirm it.

Each suggestion waits with a note such as N possible bills found. Not counted yet. Opening Review shows one at a time, with its amount, cadence, and the last four charges as evidence. In the demo, two are waiting: APPLE.COM/BILL and CLIPPER SERVICE, left there so you can try the choices. Then you choose:

Confirm it. The name and category are kept, and you can edit them afterwards.

{% endcall %} {% call step("Not recurring") %}

The Overview shows what is left to pay this month, what has been paid, and the income expected. A series that moves money between your own accounts, such as a card's autopay, is labelled Not in totals. Its payments are shown, but they are not counted twice, because the card's own purchases already count.

{{ figure("recurring-page", "The Recurring Overview: this month's totals, the Needs attention list, and the bills in date order.", "Recurring, with this month's totals and the bills in date order.") }} {{ try_it("/recurring", "Open Recurring", "Overview, Calendar, and All bills show the same series in three ways.") }} {% endcall %} {% call section("questions", "Questions omsync asks") %}

When a charge is outside a bill's usual amount but looks like the same bill at a new price, omsync flags it New amount?. It counts that payment as paid and does not mark it missed, and it does not change the amount by itself. You can accept the new amount, which takes effect from that charge onward, or choose Not this bill if the charge is something else.

Two charges can seem to pay the same due date. Then omsync asks which one, in Needs attention, rather than picking one silently. A bill that you pay from an account omsync does not track can be marked Paid elsewhere for that due date.
