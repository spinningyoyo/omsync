The first of these wins:

  1. You. A category or a split that you set stays until you change it.
  2. A receipt.
  3. A keyword: text in the payee. For example, NETFLIX sets Subscriptions.
  4. A rule, only when no keyword fits.
  • Triage lists payees with no keyword. One keyword then covers all of their transactions.
  • Preview shows what a keyword or rule would change. Nothing is saved until you add it.
  • You need no keywords for Zelle, Venmo, transfers, or Square. omsync reads how the money was paid from the bank's text.
  • The parts of a split must add up to the transaction amount.
