A header has up to three parts, in this order on the right side: - joint_menu: the joint-share choice, My half or Full. It is one setting for the whole app, so every page whose amounts it changes has this same control, and the panel says so. It is shown only when an account is joint (shell_context gives joint=None otherwise). - period_menu: what period the page shows. The current choice is on the button; the presets and Custom are links in its panel, so the page works without JavaScript once it is open. - page_actions: one menu for what can be done with the page, such as Print and Export. A new action is an item here, not another button.
